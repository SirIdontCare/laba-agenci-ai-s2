# Pomoc od zera

**Nie wiesz, gdzie kliknąć albo co wkleić? Zacznij tutaj.**

Cel pierwszej lekcji: **działający chatbot pod własnym linkiem, dostępny po wpisaniu hasła**. W tej pomocy przechodzimy przez każdy etap jego uruchomienia. Wracaj do niej wtedy, kiedy potrzebujesz.

## Trzy miejsca pracy

| Miejsce | Co tam robisz | Przykład |
|---|---|---|
| Rozmowa w Codex / Claude Code | Zlecasz zmianę w aplikacji | „Dodaj ekran hasła” |
| Terminal, czyli okno poleceń | Uruchamiasz programy | `npm.cmd run dev` |
| Przeglądarka | Sprawdzasz stronę i ustawiasz konta | Otwierasz adres localhost albo panel Vercel |

Jeśli instrukcja mówi **„wklej do asystenta”**, wklej tekst do jego rozmowy. Jeśli mówi **„wpisz w terminalu”**, wpisz komendę w oknie poleceń. Adres strony wpisujesz w pasek adresu przeglądarki.

## Jak przechodzić instrukcje

1. Otwórz jeden etap.
2. Wykonaj jedną czynność.
3. Porównaj wynik z opisem „Gotowe, gdy”.
4. Jeżeli wynik się zgadza, przejdź dalej.
5. Jeśli nie — otwórz wskazany problem. Nie zaczynaj od instalowania wszystkiego ponownie.

Kolejność: **narzędzia → folder aplikacji → asystent → lokalna strona → model → hasło → GitHub → Vercel → test linku**.

## Jak poprosić o pomoc

Skopiuj i uzupełnij:

```text
Etap / numer kroku:
System: Windows / macOS
Narzędzie: Codex / Claude Code / terminal / przeglądarka
Co zrobiłem:
Co miało się pojawić:
Co pojawiło się zamiast tego:
Dokładny komunikat błędu:
Co już sprawdziłem:
```

Dodaj zrzut, jeśli pomaga pokazać problem. Ukryj klucze, hasła i dane prywatne. Nie załączaj pliku .env.local. Jeśli nie znasz odpowiedzi na któreś pole, napisz „nie wiem”.
