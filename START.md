# Jak pracujemy

## Najpierw przygotuj środowisko

Otwórz [instrukcję instalacji i zakładania kont](INSTALACJA_I_KONTA.md). Na pierwsze spotkanie potrzebujesz Node.js, Git, GitHub, Vercel oraz Codex lub Claude Code.

## Dwa foldery

- **Materiały kursu** — pobrane z GitHub instrukcje.
- **moj-agent** — Twoja aplikacja, rozwijana przez cały kurs.

Nie uruchamiaj npm install w folderze samych materiałów. Ta komenda ma sens w folderze aplikacji, w którym znajduje się package.json.

## Jedno ćwiczenie naraz

1. Otwórz [lekcję 1](lekcja_01.md).
2. Wybierz ćwiczenie wskazane przez prowadzącego.
3. Otwórz folder aplikacji w asystencie.
4. Wklej polecenie z ćwiczenia.
5. Uruchom aplikację i sprawdź wynik według checklisty.
6. Zapisz działającą wersję.

Gdy pojawi się błąd, wklej go asystentowi i poproś o wyjaśnienie oraz naprawę. Sam komunikat „gotowe” nie wystarczy — sprawdź stronę.

## Klucz od LABA

Klucz OpenRouter dostaniesz prywatnie. Dodaj go do .env.local w swoim projekcie, a przy publikacji także do ustawień środowiska Vercel. Nie wklejaj go do promptu, kodu strony ani repozytorium. Pliki .env muszą być wykluczone przez .gitignore.
